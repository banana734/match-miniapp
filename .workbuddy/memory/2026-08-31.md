  family_trial_feedback / mentor_trial_feedback）+ 4 个视图。

  线上 API 基址 https://jymlbzjmwtbw.sealosbja.site/api（src/utils/api.js）。

### 架构要点
- 身份一旦绑定即锁定：bindRole 与 saveProfile 双重校验 lockedRole，
  一个微信只能有一个身份。
- 登录降级：未配置 WECHAT_APP_ID/SECRET 时用前端 devClientId
  生成 dev-openid-xxx 回退登录，保证开发流程不断。
- 试课状态机：pending → formal（愿意）/ rejected（不愿意）/
  pending（需调整）/ removed（手动移除）。
- 资料存在 users.profile_json（JSON 列），靠 4 个 MySQL 视图用
  JSON_EXTRACT 摊平成列，供管理后台查询。
- useOrderedTagGroup 实现「按点击顺序排序」的多选标签（科目/困难/特质）。
- safeSwitchTab 防止重复切 tab 触发 timeout。
