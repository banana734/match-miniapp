## BUG 修复：`navigateTo:fail timeout`（非超时设置问题）

### 现象
- 控制台偶发 `navigateTo:fail timeout`；用户误以为是"等待时间设太短"。

### 根因（已核实，非超时配置）
- `navigateTo:fail timeout` = 目标页在框架时限内没打开，通常是**导航竞态/目标页问题**，uni/微信**没有可手动配置的导航超时**。
- 排查链路：登录/选身份/首页守卫用的都是 `switchTab`/`reLaunch`（正确）；所有 `navigateTo` 目标（notice、mentor-data、family-data、各反馈页）在 `src/pages.json` 与编译产物 `dist/*/mp-weixin/app.json` 均**已注册、且都不是 tabBar 页**。
- 真正触发点：`src/pages/match/match.vue` 与 `src/pages/message/message.vue` 的 onShow 守卫里，**在资料未填时同步 `navigateTo('/pages/notice/notice')`**。这两个页是 tabBar 页，刚 `switchTab` 切过来 onShow 立即 navigateTo，与 tab 切换生命周期竞态 → 偶发 timeout。

### 修复
- 把两处 onShow 内的 `navigateTo` 用 `setTimeout(..., 60)` 延后一帧，避开竞态。tap 触发的 navigateTo（goToTrialFeedback 等）不受影响，无需改。
- dev 编译进程已热更新（多次 DONE Build complete）。

### 给用户的话术
- 不是超时设置问题；是 onShow 里同步 navigateTo 与 tab 切换打架。已延后执行修复。微信开发者工具点「重新编译」即可生效。

## 表单页统一样式 + 顺手修 `reLaunch:fail timeout`

### 需求
- 用户发现「反馈页」和「资料填写页」样式不一样，要求表单页样式统一。

### 根因（样式差异来源）
- 全部表单样式集中在全局 `src/styles/common.scss`（被 `App.vue` 的 `<style lang="scss">@import</style>` 引入），6 个表单页共用同一套 class。
- 唯一真正的视觉分歧：**多选控件**。
  - 资料填写页（mentor-data / family-data）：多选 = **标签芯片** `.subject-list`/`.subject-tag`（圆角胶囊，选中变蓝，且按点击顺序显示 1. 2. 3. 用于排序）。
  - 反馈页（试课×2 / 日常×2）：多选 = **原生勾选列表** `<checkbox-group>`/`<checkbox>`。
  - 单选（是否愿意合作）、输入框、标题、提交按钮等其余控件两边早已一致。

### 统一方向
- 只能统一成**芯片**：资料页多选带"点击顺序排序"是功能，不能退化成普通勾选框；反馈页只是"随便勾"，用芯片（不带序号）即可完美对齐且不失功能。

### 改动
- 4 个反馈页（mentor-feedback / family-feedback / mentor-daily-feedback / family-daily-feedback）：把 3 个多选题的 `<checkbox-group>` 换成与资料页一致的 `<view class="subject-list">` + `.subject-tag`（`:class="{active: form.xxx.includes(item)}"` + `@tap="toggleChoice(...)"`）。
- 每个反馈页新增页面级 `toggleChoice(field, otherField, value)`（加入/移出数组，取消"其他"时清空自定义输入），与资料页 `toggleXxx` 写法一致；删除原 3 个 `handleXxxChange`（checkbox 事件）处理函数。
- 单选"是否愿意合作"保留 `<radio-group>`（`handleContinueChoiceChange` → 组合式 `handleChoiceGroupChange`），不变。

### 顺手修的 `reLaunch:fail timeout`
- 现象：控制台 `reLaunch:fail timeout`（上一轮只修了 navigateTo 的同类竞态，reLaunch 没动）。
- 根因：home / My / match / message 四个页面的 onShow 守卫里**同步调用 `uni.reLaunch`**（未登录→登录页、未选身份→选身份页），与页面加载/tab 切换生命周期竞态。
- 修复：把 4 处的 `reLaunch` 用 `setTimeout(..., 60)` 延后一帧，与 navigateTo 修复同套路。
- `npm run build:mp-weixin` 验证编译通过（exit 0，仅 Sass `@import` 弃用警告，无害）。

### 给用户的话术
- 反馈页多选现在和资料页长得一样了（都是圆角胶囊芯片）。reLaunch 超时也一并修了。重新编译即可看到。
