## 08:38 镜像拉取失败根因确认 + 修法
- Docker Hub 实测：仓库公开（is_private:false）、`sha-9704993` 存在且为 linux/amd64、匿名 manifest 拉取 200、与 `latest` digest 完全相同（sha256:d116ae8e...）→ 镜像本身无任何问题。
- 结论：Sealos 拉取代理在 tag 推送前拉过一次 not found，**负面缓存**了 404，之后 ImagePullBackOff 一直回放缓存的"不存在"。
- 修法：Sealos「变更」里把镜像 tag 改成 `latest`（同一镜像、新 tag 字符串绕过缓存），保存后等 Pod running。
- 注意：旧 Pod 已被替换掉、新 Pod 起不来 → 此刻线上服务是中断的，操作要立即做。
- 用户的镜像是 GitHub Actions 自动构建的（tag 形如 sha-<commit>，仓库有 GITHUB_ACTIONS_SETUP.md），以后推新代码 → Actions 自动出新 tag → Sealos 变更 tag 即可。
