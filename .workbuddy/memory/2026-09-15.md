## 新增：「我的」页「重置开发身份」按钮（开发调试）

### 痛点
- 小程序开发回退登录（`server/routes/auth-real.js` 用 `dev-openid-${devClientId}` 当 openid，而 `devClientId` 永久存进 `match-dev-client-id` storage）会记住旧账号；加上 `match-user-state` 让 `restoreEntry()` 打开就跳过登录与选身份。结果：每次进小程序都是旧账号，无法完整体验「登录→选身份→匹配→试课→日常反馈」全流程。

### 改动
- `src/store/user.js`：新增 `resetLoginState()`（清空内存登录态 + `removeStorageSync('match-user-state')` 和 `removeStorageSync('match-dev-client-id')`），并加入导出。
- `src/pages/My/My.vue`：在「查看或修改已填写资料」按钮下方加小字按钮 `重置开发身份（开发调试）`，`@tap="resetDevIdentity"`。
- `src/pages/login/login.vue`：**已撤回**此前临时加在登录页的按钮，保持登录页干净。

### 用法
- 想重走全流程：进入「我的」页 → 点底部「重置开发身份」→ 弹窗确认后调用 `resetLoginState()` → `uni.reLaunch` 回登录页 → 下次登录生成全新 openid（全新账号），从登录页重走完整流程。
- 注意：此按钮针对**开发回退模式**（未配微信密钥）。真实微信登录时 openid 由微信 code 决定，清本地缓存无法换号。
